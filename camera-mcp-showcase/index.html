全流程 8 步

1. 环境盘点

Blender 5.2.1、uv 0.12.5、Claude Code CLI；已有旧版插件 v1.5。

2. 升级插件

官方源被墙，走 jsDelivr 镜像下到最新 v1.7，旧版备份为 .bak，原地覆盖保留勾选。

3. 注册服务端

claude mcp add blender -- cmd /c uvx blender-mcp，握手 √ Connected。

4. TCP 探活

直接打 9876 发 get_scene_info，真实读回 38 个物体，确认桥接通。

5. 启动 Claude Code

后台起的窗口在非交互会话里看不见，改在桌面 Win+R 唤起才正常。

6. 授权放行

对 execute_blender_code 选“本目录不再询问”，后续不打断。

7. 提交任务

原 38 个物体收进 OriginalScene 集合挪到 15 米外（不删除），在原点开工。

8. 七部件依次落成

机身→镜头→侧控→细节→热靴拨盘→快装板→电池仓；材质分金属/玻璃/橡胶/屏幕。

三个必须如实说的坑

盲建模：视口截图回传失败，Claude 全程看不到结果，只靠坐标和包围盒校验。
低模占位：镜头环有棱面、按键是小盒子堆的，离产品级渲染还差精修。
授权弹窗：新工具类型首次调用要手动放行一次。
